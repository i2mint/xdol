xdol.tiering#

A bounded hot store over a cold source of truth (write-through, GDSF release).

TieredStore(hot, cold, budget_bytes=...) is a MutableMapping: writes go to cold first, then hot; reads are served from hot when present, else from cold (and admitted to hot when the policy says so). Placement is decided by a PlacementPolicy (default GdsfPolicy: Greedy-Dual-Size-Frequency with aging, Cherkasova 1998) from the statistics of an xdol.access.AccessLog, whose clock is the store’s clock.

Verbs are free functions, store first: sweep(), pin(), unpin(), status(), prefetch(), local_paths().

Values must support len (their size in bytes): __setitem__ raises TypeError before writing anything otherwise. A value read from cold without len counts as size 0. Single-threaded: there is no locking.

>>> hot, cold = {}, {}
>>> store = TieredStore(hot, cold, budget_bytes=None, tracker=AccessLog())
>>> store['a'] = b'hello'
>>> cold['a'], hot['a']
(b'hello', b'hello')
>>> status(store)['hot_bytes']
5

Bases: _ResidencyPolicy

Greedy-Dual-Size-Frequency with aging, plus pins, minimum residency and second-hit admission.

Each hot key carries H = L + F * cost(size) / size, fixed when it is accessed, with F its accesses since admission to hot, cost(size) = cost_per_request + cost_per_byte * size and L the H of the last released key at that time (per process; resets at restart). Releasing the lowest H raises L, so a key not accessed for a while loses to newer ones however often it was read. A key already hot when this process first sees it starts fresh, F = 1, as if just admitted: its logged history (often long, all of it older than L’s reset) would otherwise keep it favoured after every restart. A key not accessed during this process (a cron sweep) is ranked on its recency instead: F is 0.5 ** (age / seed_half_life_s), age being the time since its last_access, so among such keys of equal size the least recently used goes first (a key seeded this way and then accessed continues from F + 1).

class xdol.tiering.TieredStore(hot, cold, *, budget_bytes, policy=None, tracker=None, max_item_fraction=1.0)[source]#

Bases: MutableMapping

Bounded hot store over a cold source of truth. See the module docstring.

Parameters:

  • budget_bytes (int | None) –

    None: hot is a full mirror (never released, every read miss admitted); 0: cold-only, no hot tier (writes skip hot and read misses are not admitted, but only sweep() enforces it: prefetch() and local_paths() still fill

    hot until the next sweep, which releases every hot copy, protected or not); > 0: bounded.

  • policy (PlacementPolicy | None) – a PlacementPolicy; default GdsfPolicy.

  • tracker (AccessLog | None) – an AccessLog (its clock is the store’s clock); default xdol.access.default_access_log_for() (hot).

  • max_item_fraction (float) – in (0, 1]; with a bounded budget, an item larger than max_item_fraction * budget_bytes is never held hot by the store itself: a read miss is served from cold without admission, and a write goes to cold only (dropping any stale hot copy). The default 1.0 keeps only items larger than the whole budget out. prefetch() and local_paths() are explicit requests and are exempt.

Keys already in hot at construction are not recorded as accesses. Their size comes from the tracker, else from the file size when hot is file-backed, else counts as 0 until the key’s next hot hit.

xdol.tiering.local_paths(store, *, path_of=None)[source]#

Read-only {key: real file path}; materialises each key into hot.

Materialisation is an explicit request, like prefetch(): exempt from the policy and from max_item_fraction.

path_of(key) gives the file path of key in hot; the default is dol.path_of() on the hot store, which follows wrapped layers (TypeError on access if hot is not file-backed, before anything is fetched; KeyError for a key leaving its root). FileNotFoundError is raised if the file is not there after materialisation. key in paths checks the store without fetching.

Release hot copies, lowest priority first, down to the low watermark.

Never touches cold, nor the keys in exclude. Warns if every remaining key is protected, once per stuck episode (until a sweep reaches it again). With budget_bytes=0 (no hot tier) every hot copy is released, protected or not.
