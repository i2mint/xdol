xdol.keys#

Robust, stable cache keys: turn a call’s inputs into a short, filesystem-safe string.

A persistent cache (see xdol.memoize) is only as good as its keys. A key must be

  • stable across runs and machines – never derived from a memory address, set iteration order or dict insertion order;

  • insensitive to superficial differences – dict key order, surrounding whitespace;

  • loud about what it cannot make stable – an object whose only description is <Foo object at 0x7f...> would give a different key every run (a cache that never hits, or, in replay-only mode, a spurious miss), so it raises UnstableKeyError instead of silently hashing the address.

>>> robust_key({"b": 1, "a": 2}, prompt="  hi ") == robust_key({"a": 2, "b": 1}, prompt="hi")
True
>>> len(robust_key(1, 2, x=3))
32

Keys are a stability contract: committed caches (e.g. cassette directories) are keyed by these hashes, so the output for JSON-able inputs does not change between releases.

Customize with make_key_func() – drop non-semantic arguments (callbacks, loggers), bind to the wrapped function’s signature, pick the digest, or teach it your own types with a __cache_key__ method.

>>> def f(prompt, *, logger=None, retries=3): ...
>>> key = make_key_func(f, drop=["logger", "retries"])
>>> key("hi", logger=print) == key(prompt="hi", retries=9)
True

xdol.keys.make_key_func(func=None, *, drop=(), apply_defaults=False, collapse_whitespace=False, on_unstable='raise', digest='sha256', length=32, prefix='')[source]#

Build a key function (*args, **kwargs) -> str, customized.

Parameters:

  • func (Callable | None) – if given, calls are bound to its signature first, so f(1, 2), f(1, b=2) and f(a=1, b=2) share a key. Required for drop.

  • drop (Iterable[str]) – names of parameters of func to leave out of the key – the non-semantic ones (callbacks, loggers, timeouts, self).

  • apply_defaults (bool) – with func, also hash default values, so f(x) equals f(x, y=<default>). Off by default: adding a defaulted parameter later then does not invalidate existing caches (changing a default does not either – turn this on if that matters to you).

  • collapse_whitespace (bool) – see normalize().

  • on_unstable (Literal['raise', 'warn', 'ignore']) – see normalize().

  • digest (str) – hash algorithm (any hashlib name) and key length in hex chars.

  • length (int) – hash algorithm (any hashlib name) and key length in hex chars.

  • prefix (str) – prepended to every key (e.g. a namespace or version: "v2-").

Return type:

Callable[..., str]

With no arguments this is robust_key().

>>> make_key_func()("x") == robust_key("x")
True
>>> def f(a, b=1, *, log=None): ...
>>> k = make_key_func(f, drop=["log"], apply_defaults=True)
>>> k(1) == k(1, 1) == k(a=1, log=print)
True
xdol.keys.normalize(obj, *, collapse_whitespace=False, on_unstable='raise')[source]#

Recursively reduce obj to a JSON-able structure that is equal for equal meaning.

  • strings are stripped (and, with collapse_whitespace, inner runs of whitespace become one space – off by default since whitespace can be meaningful in code or markdown);

  • mappings get string keys, sorted; lists and tuples become lists;

  • sets are sorted; bytes are replaced by their digest; paths, enums, dates, dataclasses, numpy-like arrays and callables get a tagged, stable description;

  • an object with a __cache_key__() method is described by what it returns;

  • pandas objects are described by their full content; bound methods by function and instance; lambdas raise (indistinguishable);

  • anything else falls back to repr, vetted by on_unstable (see UnstableKeyError). A repr can still be lossy (truncated, or leaving out

    state): for such types define __cache_key__.

Limitation: recursion costs ~2 frames per nesting level, so structures nested deeper than ~400 levels raise RecursionError.

>>> normalize({"b": " x ", "a": (1, 2)})
{'a': [1, 2], 'b': 'x'}
>>> normalize({3, 1, 2})
{'__set__': [1, 2, 3]}
Return type:

Any

xdol.keys.robust_key(*args, **kwargs)[source]#

The default key function: a stable SHA-256 (32 hex chars) of the normalized call.

Calls whose arguments are semantically equal – same values up to dict key order and surrounding whitespace – get the same key.

>>> robust_key("a", n=1) == robust_key("a ", n=1)
True
>>> robust_key("a", n=1) == robust_key("a", n=2)
False
