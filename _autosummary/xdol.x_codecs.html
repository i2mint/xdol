xdol.x_codecs#

Extra codecs: object <-> bytes pairs, and stores that apply them.

Besides resolve_values_to_bytes(), this module holds the value-encoding half of the persistent memoizer (xdol.memoize):

  • Codec – an encode/decode pair, with ready-made JSON_CODEC (human-readable, diff-friendly), TEXT_CODEC and BYTES_CODEC (pass-through, for images/audio), looked up by name through get_codec();

  • with_codec() – apply a codec to the values of a bytes store;

  • paired_store() – for a result that mixes metadata and a binary asset, a store whose value is (metadata, asset_bytes), persisted as <key>.json + <key>.bin.

>>> store = with_codec({}, "json")
>>> store["k"] = {"b": 1, "a": [1, 2]}
>>> store["k"]
{'a': [1, 2], 'b': 1}
>>> raw = {}
>>> pairs = paired_store(raw)
>>> pairs["img1"] = ({"prompt": "a cat"}, b"PNGDATA")
>>> sorted(raw)
['img1.bin', 'img1.json']
>>> pairs["img1"]
({'prompt': 'a cat'}, b'PNGDATA')

class xdol.x_codecs.PairedStore(store, *, meta_codec='json', meta_suffix='.json', asset_suffix='.bin')[source]#

Bases: MutableMapping

Values are (metadata, asset_bytes) pairs, kept as two entries in a bytes store.

store[k] = (meta, blob) writes k + asset_suffix (blob verbatim) and k + meta_suffix ({"asset_sha256": ..., "meta": meta} through meta_codec). The metadata entry is written last and is what makes a key exist, so a crash mid-write leaves no half-entry that reads back as valid; in/iteration/len only see keys whose both halves are present. The digest guards against two writers of the same key interleaving (A’s metadata with B’s asset): such a pair raises CodecDecodeError on read instead of returning the chimera. Entries in the older bare-metadata layout are still read (unverified).

xdol.x_codecs.json_codec(*, indent=2, default=None)[source]#

A JSON Codec: keys sorted, non-ASCII kept, so stored files diff well.

Strict by default: a value JSON cannot represent raises TypeError rather than being silently stringified. Pass default= (as in json.dumps()) to opt in.

>>> c = json_codec(indent=None)
>>> c.decode(c.encode({"b": "é", "a": 1}))
{'a': 1, 'b': 'é'}
>>> c.encode({"b": 1, "a": 2})
b'{"a": 2, "b": 1}'
